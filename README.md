# Doodle & Do ✦ 

This is a simple To-Do List website that I made using HTML, CSS and JavaScript.

I built this project to practice the basics of web development and to get more comfortable with JavaScript.

## What it can do

* Add tasks
* Edit tasks
* Delete tasks
* Mark tasks as completed
* Clear all tasks
* Shows the number of tasks
* Saves tasks using Local Storage
* Works on mobile screens too

## Built with

* HTML
* CSS
* JavaScript

## How to use

You can open `index.html` in your browser.

If you're using VS Code, you can also open it with Live Server.

## A little about the project

This was one of my first web projects. I wanted to make something simple but useful while learning how HTML, CSS and JavaScript work together.

I'm planning to keep improving it and add more features as I learn more.
